Hotel Booking Management System
A simple CLI-based Hotel Booking Management System developed in Java.
This project helps manage hotel room bookings using the terminal/console.

Features
View Available Rooms
Book a Room
Cancel Room Booking
View Booked Rooms
Input Validation
Error Handling
Console-Based Interface

Technologies Used
Java
ArrayList
Scanner Class
Exception Handling
Collections

Project Type
CLI (Command Line Interface)
Console-Based Application

How to Run
Step 1: Compile
javac HotelBookingManagementSystem.java
Step 2: Run
java HotelBookingManagementSystem

1. View Available Rooms
2. Book Room
3. Cancel Booking
4. View Booked Rooms
